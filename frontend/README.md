# FlowOps Frontend

Aplicación React construida con Vite que implementa el sistema de diseño *FlowOps – Surgical Precision*. Consulta el [README principal](../README.md) para instrucciones completas de instalación y uso.

## Inicio rápido

```bash
npm install
npm run dev
```

Requiere el backend corriendo en `http://localhost:8000`.
